# sustainability-greece
Sustainable Greece: My experiences traveling and researching sustainable practices and their impact in Greece

An interactive, map-driven web experience documenting sustainability initiatives across Greece, built from my experiences as a Gilman Scholar and University of Washington study abroad student. The project combines immersive visual storytelling with geospatial data to highlight renewable energy, infrastructure, and environmental practices encountered during my travels.

🔗 **Live Site:**  
`https://sustainability-greece.vercel.app`

---

## Project Overview

This project explores sustainability efforts in Greece through:
- A scroll-driven narrative experience
- Interactive Google Maps with custom markers
- Category-based filtering of sustainability locations
- Visual storytelling through photos, gradients, and transitions

The site is designed to be informative, engaging, and accessible, while demonstrating modern front-end engineering practices.

---

## Features

- **Scroll-based storytelling** with dynamic background transitions  
- **Interactive map visualization** using Google Maps API  
- **Custom map markers** (wind, solar, hydro, recycling, etc.)  
- **Hover tooltips** displaying location metadata  
- **Responsive design** optimized for desktop and mobile  
- **Deployed on Vercel** for fast global delivery  

---
